# Sistema de Gestión de Inventario Petrolero
Proyecto académico desarrollado en Java con Spring Boot, aplicando la arquitectura Modelo-Vista-Controlador (MVC).
El sistema permite administrar materiales utilizados en operaciones petroleras, registrar pedidos, controlar las existencias disponibles y actualizar automáticamente el inventario al realizar entregas.

### Funcionalidades
- Registro, consulta, edición y eliminación de materiales.
- Gestión de pedidos y sus estados.
- Validación de cantidades disponibles.
- Actualización automática del stock.
- Autenticación de usuarios.

### Tecnologías utilizadas
- Java y Spring Boot.
- Thymeleaf, HTML y CSS.
- MySQL y Spring Data JPA.
- Spring Security.
- Maven.
